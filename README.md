## 
### Enfoque de Desarrollo

🔹 **Spec Driven Development (SDD)**

Trabajo bajo un enfoque de desarrollo guiado por especificaciones:

- Definición clara de requerimientos antes de implementar.
- Documentación estructurada como fuente de verdad.
- Reducción de ambigüedad en el desarrollo.
- Mayor calidad y mantenibilidad del código.

🔹 **GitFlow (flujo profesional de trabajo)**

Uso un flujo de trabajo basado en GitFlow:

- main → entorno de producción.
- develop → rama de integración.
- feature/* → desarrollo de nuevas funcionalidades.
- Control de versiones limpio, escalable y preparado para equipos.
